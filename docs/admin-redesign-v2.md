# Редизайн TWA и админки v2 (16.11.2026)

Мокап, согласованный с владельцем: артефакт «TWA и админка: редизайн», страница «v2 — по ремаркам»
(ссылка — в `HANDOFF.md`). Здесь — что из него в коде и какие правила за этим стоят.

## Правила владельца

1. **Карточка заказа — главное.** Её открывают по коду после обращения в поддержку. Скелет информации
   прежний; всё в порядке — одна зелёная строка, текст только при проблеме. Выкупленный — «Выкуплен
   <дата> · кто», без объяснений про Roblox.
2. **«Ответ клиенту» — только если покупатель писал.** Молчит — в карточке только выкуп.
3. **Главная:** Коды и Прямые — отдельные цветные блоки наверху → «Первым делом» (торопят, подняты,
   «не дошло») → ориентир по открытым заказам → «Пока вас не было» без рутины → статистика.
4. **«Выкуплено» в TWA — крупная подписанная кнопка**, отдельно от ID: она шлёт уведомление клиенту.
5. **Выкуп:** старт с баланса аккаунта, проблемные — отдельно сверху, режим «по одному» в TWA.

## Поведенческие изменения

- **Не та цена пасса** (`live.priceMismatch`) — главное действие «Написать», а не «Выкуплено»
  (`primaryActionFor` в `src/lib/order-presentation.ts`, общее для TWA и сайта). «Выкуплено» остаётся
  в меню на случай «купили другой пасс».
- В ленте TWA больше нет полосы из 5 шагов (она в шторке); проблему пасса теперь говорит только
  строка-флаг, поэтому она не уступает полосе.
- «Повторить уведомление о выкупе» переехало в меню «···»; в карточке кнопка — только если
  уведомление не дошло.
- «Пока вас не было» в TWA: по умолчанию слова покупателей, события WB и прямые заказы; ники, пассы,
  выкупы — строкой «Само, без вас»; вся лента — по кнопке.

## Не сделано (сознательно)

- «Хронология» в карточке TWA не слита с «Путём» — «Лента» осталась отдельным блоком.
- «Сначала починить» на сайте видит только вкладку «Ошибки»; заказ с не той ценой, ещё не
  упавший в ошибку, остаётся в общем списке (в TWA его кнопка уже «Написать»).
