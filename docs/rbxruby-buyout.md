# Автовыкуп через RBXRUBY

С 28.11.2026. Площадка rbxruby.io выкупает геймпасс покупателя у своих продавцов,
мы платим долларами с баланса мерчанта. Документация API: https://rbxruby.io/docs.

## Как устроено

- `src/lib/rbxruby.ts` — клиент API (`api-key`), подпись вебхука, расчёт резерва.
- `src/lib/rbxruby-buyout.ts` — воркер: отбор, проверки, отправка, синк, закрытие заказа.
- `/api/internal/rbxruby/tick` — тик раз в минуту из TG-бота (HMAC `BOT_PAYMENT_API_SECRET`).
- `/api/webhooks/rbxruby` — вебхук площадки (md5-подпись), ускоряет закрытие; без него
  тик доводит то же опросом `orders/info`.
- `scripts/rbxruby-probe.mjs` — только чтение: баланс и сток по курсам.

Режим переключается кнопками в плашке RBXRUBY (сайт «Обзор»/«Выкупить», TWA главная/«Выкупы»)
и хранится в `WbSyncCursor` stream `rbxruby` (там же снимок баланса/стока последнего тика).
Без кнопки действует env Web `RBXRUBY_MODE` (по умолчанию `dry`); `RBXRUBY_MODE=off` в env —
рубильник сильнее кнопок. Отправленные заказы доводятся до итога и на паузе.

Админка (`/api/admin/rbxruby` и `/api/twa/rbxruby`, общий `src/lib/rbxruby-route.ts`):
плашка (режим, баланс, сток ≤ потолка, сутки/неделя, следующие), метка в строках
«Первым делом» (`rbxruby` в `loadFirstInLine`), блок в карточке заказа — хроника и кнопки
«Отправить сейчас» (те же проверки, вне очереди), «Отменить» (только Queued/Error у площадки),
«Не отдавать» (`RBXRUBY_EXCLUDE`).

Режимы:

| Режим | Что делает |
| --- | --- |
| `off` (по умолчанию) | ничего |
| `dry` | читает баланс/сток, проверяет пассы у площадки, пишет в лог бота «отправил бы» — заказов НЕ создаёт |
| `on` | создаёт заказы |

Остальные env Web: `RBXRUBY_API_KEY`, `RBXRUBY_MAX_RATE` (наш потолок $/1k, 3.8),
`RBXRUBY_MAX_PER_TICK` (2), `RBXRUBY_DAILY_ROBUX` (30 000 R$ цен пассов за сутки).

## Какие заказы уходят

Порядок — как в блоке «Первым делом» (`loadFirstInLine`): поднятые вручную → не
дошло → прямые → «Ебут мозги» (тон ИИ, число обращений) → «Спрашивают» → остальные
по возрасту. Кто ебёт мозг — закрывается через RBXRUBY первым.

`PENDING`, не тест, не заморожен, без пометок (`flaggedAt`), не неоплаченный прямой,
один пасс (разбивку не трогаем), ни разу не отправлявшийся. Перед отправкой:
`assertOrderBuyable`, пасс на продаже и цена = `ceil(номинал/0.7)` (мост), площадка
видит этот пасс у владельца на плейсе (`orders/gamepass/passes`), баланс покрывает
резерв, на складе есть продавец по курсу ≤ потолка.

Отправленный заказ → `IN_PROGRESS` (рука его не выкупит параллельно), событие
`RBXRUBY_SUBMIT`. Итог — `RBXRUBY_RESULT`:

- `Completed` → заказ `COMPLETED`, себестоимость по факт. курсу × `usdToRub`,
  покупателю обычное «выкуплено», в заметке — $ и аккаунт продавца.
- `Error`/`Cancelled` → резерв снимаем, заказ обратно в `PENDING` с заметкой,
  пуш в «К выкупу». **Автоматом повторно не отправляется.**
- Если человек закрыл/заморозил заказ, пока у площадки `Queued`, — отменяем у неё.

Id у площадки: `rb-<код гейта>`.
